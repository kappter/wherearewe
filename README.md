# Where Are We?

A small astronomy hub for visual tools that turn cosmic distance and motion into something we can picture.

- **[Scale the Cosmos](scale.html)** compares six distances—from Earth–Moon to Milky Way–Andromeda—using a basketball, baseball, golf ball, or a custom-sized object as the model scale.
- **[Sun at Light Speed](https://kappter.github.io/sun-at-light-speed/)** explores a geometric model of an object moving around Earth at a chosen speed and compares its current position with the light arriving here.
- **[Skyarc](https://kappter.github.io/skyarc/)** explores when celestial objects rise, reach their highest point, and set for a selected place and date.

The hub and scale tool are self-contained static pages. The scale tool includes its assumptions and source links in the page.
