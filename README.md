# Where Are We?

A small astronomy hub connecting two visual thought experiments:

- **[Sun at Light Speed](https://kappter.github.io/sun-at-light-speed/)** — explore a geometric model of an object moving around Earth at a chosen speed, and compare its current position with the light arriving here.
- **[Skyarc](https://kappter.github.io/skyarc/)** — explore when celestial objects rise, reach their highest point, and set for a selected place and date.

The landing page is a self-contained static site in `index.html`, designed for GitHub Pages.

Live site: https://kappter.github.io/wherearewe/
